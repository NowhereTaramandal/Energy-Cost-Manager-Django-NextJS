# Demonstration Flow

1. Run migrations and seed demo plans.
2. Create a superuser and show provider/tariff administration in Django Admin.
3. Register a normal user in the frontend.
4. Upload `sample-data/sample_usage.csv`.
5. Show the processed reading count, interval length and total kWh.
6. Open Usage Analytics and explain the daily and hourly graphs.
7. Open Energy Plans and explain flat vs time-of-use tariffs.
8. Open Compare Plans, select the uploaded file and select a current plan.
9. Run the comparison and explain annualisation, usage cost, supply cost and savings.
10. Open Recommendations and show the three lowest estimated annual costs.
11. Open Reports and download the CSV comparison report.
12. Open History to demonstrate persistence.
